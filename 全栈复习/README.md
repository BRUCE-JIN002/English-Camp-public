## 如何使用

每篇优先讲当前实现，再解释适用原理，最后指出具体边界和练习。源码定位可以作为复习入口，不需要背整段实现。遇到“后续、可以、改进”字样时，代表尚未落实的方案，不能当作已完成项目经验。

建议用五次练习完成一轮：先画架构和身份链路；再手写支付时序；第三次演示角色切换和音频播放；第四次分析任务与注销失败；最后脱稿回答面试篇问题并回源码核对。

本次整理只修改文档，检查文档结构、链接与关键实现表述，不代表重新执行了所有集成测试或确认远端部署状态。可运行验证命令集中在第 23 篇。
